О чём это

Приложение knittingarchbuccal-upload — личный инструмент автора канала для загрузки собственных роликов на YouTube. Публичного сервиса нет, сторонние пользователи к нему не подключаются.

Какие данные используются

Приложение запрашивает доступ к YouTube Data API в объёме двух разрешений:

  • youtube.upload — загрузка видео на собственный канал автора;
  • youtube.readonly — чтение статистики собственных роликов.

Данные используются только для этих двух действий.

Хранение

Токен доступа хранится в единственном файле на локальном компьютере автора и никуда не передаётся. Серверов у приложения нет, база данных не ведётся. Персональные данные третьих лиц не собираются и не обрабатываются.

Передача третьим лицам

Никакие данные не передаются третьим лицам, не продаются и не используются для рекламы или обучения моделей.

Отзыв доступа

Доступ отзывается в любой момент на странице Google Account → Сторонние приложения. После отзыва приложение теряет возможность работать с каналом.
